# Florion Petcare — Sistem Informasi Klinik Hewan

Sistem informasi terintegrasi untuk pendaftaran pasien, rekam medis, transaksi, dan laporan pada klinik hewan **Florion Petcare**, dibangun dengan **Expo (React Native)** di sisi mobile dan **Laravel** di sisi backend.

---

## Deskripsi Proyek

Florion Petcare adalah klinik hewan yang berlokasi di Sawahlunto, Sumatera Barat. Saat ini seluruh proses pendataan masih dilakukan secara manual menggunakan buku, Microsoft Excel, dan WhatsApp. Proyek ini bertujuan membangun sistem informasi yang mampu:

- Mendaftarkan pemilik dan pasien hewan.
- Mencatat riwayat medis, diagnostik, pengobatan, dan perawatan.
- Mengelola rawat inap.
- Mencatat transaksi pembayaran.
- Menyediakan laporan kunjungan dan keuangan.
- Menampilkan dashboard ringkasan.

## Fitur Utama

- Login dan manajemen hak akses (admin, dokter, paramedik).
- Pendaftaran pemilik dan pasien hewan.
- Pencarian pasien dan pemilik.
- Rekam medis dan riwayat pasien.
- Input diagnostik, pengobatan, perawatan, dan rawat inap.
- Transaksi pembayaran dan riwayat transaksi.
- Laporan kunjungan dan laporan keuangan.
- Dashboard ringkasan.
- Backup data.
- Notifikasi WhatsApp (opsional).

## Tech Stack

| Bagian | Teknologi |
|---|---|
| Frontend (Mobile) | Expo / React Native, React Navigation, Axios |
| State Management | React Context / Zustand / Redux Toolkit |
| Backend | Laravel 11 (PHP 8.2+) |
| Database | MySQL (via Laragon untuk local development) |
| ORM | Eloquent ORM (bawaan Laravel) |
| Autentikasi | JWT (tymon/jwt-auth atau Laravel Sanctum) |
| Testing | PHPUnit (backend), Jest + React Native Testing Library (mobile) |
| API Testing | Postman / Insomnia |
| Containerization | Docker, Docker Compose |
| Deployment | Docker (VPS / Railway / Render) |
| Manajemen Proyek | GitHub (Issues, Projects, Pull Requests) |
| Version Control | Git + GitHub |
